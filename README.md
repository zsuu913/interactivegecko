# interactivegecko
gecko takes input

this is currently intended as documentation. will update readme when it should actually be working as a game

gecko now wanders an 80s style text-based adventure game map (might include mazes. unsure. i dislike mazes). since gecko is a lizard, the dangers of an 80s adventure game are even higher.
planned features: loot (ergo, score); enemies; dumb ways to die; some enemies can be befriended; savegame (and loading a save)
not planned: fighting. the gecko is too small to fight.
